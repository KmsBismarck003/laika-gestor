# Laika Club - Event Manager Module

## Overview
This repository contains the official Event Manager module for the Laika Club ecosystem. It is designed specifically for management personnel responsible for the logistical and commercial operations of events.

## Features
* Creation and lifecycle management of events.
* Commercial administration, including advertising and promotional campaigns.
* Direct oversight of merchandise and associated revenue streams.
* Access to operational analytics and performance metrics.

## Architecture
This application operates independently from the main Laika Club monolithic architecture. It establishes secure connections to the core backend microservices strictly through the Pilgrim API Gateway.

## Usage
Access is limited to authenticated users holding the Manager role. The system ensures robust authorization protocols to maintain the integrity of commercial data and event planning.
